# Project

Pure JS Shopping Project is a real world project for testing pureJS skills.

# See Online

This project is deployed on [netlify](https://www.netlify.com) to see it online without need to clone it and start it.
The project is available in https://pure-js-shopping-project.netlify.app for you.

# Language

The main language of this project is Farsi, but you can clone it change it to your language.
the products API is English so you can still use it if your language is English.

# Installation

If you want to install and change my code for yourself you can clone it form https://github.com/mohammad-mohammadi88/shopping-project with command

    git clone https://github.com/mohammad-mohammadi88/shopping-project

you don't need to install any package for using app.

# Development

To start development service you only need to edit pure files because we did not used any framework or library for JavaScript.
